# 研究方法与公开范围

## 研究问题

以容易取得的人体测量为输入，研究 DXA 身体成分的回归估算。这是一种软测量问题：目标是描述同时期测量之间的关系，不是纵向预测，也不是干预效果或因果分析。

## 源码体现的实验设计

1. 按调查周期分别读取人口、身体测量和 DXA 表；使用一对一键连接，保持周期标记。
2. 进行年龄与 DXA 状态筛选，处理缺失值、克/千克单位及不同周期可用字段。
3. 比较输入组合与回归模型；将未使用的调查周期留出以观察跨周期泛化。
4. 用残差分位数形成经验预测区间，研究全局、性别、BMI 等校准分组。
5. v0.3 嵌套流程在每个外层周期之外完成模型配置选择、校准方法选择和区间拟合。测试会改变外层标签和特征，检查其不影响该折的选择结果和区间宽度。
6. 训练得到的模型包在加载前检查版本、输入字段、目标和散列；外部验证入口要求填写数据来源与单位合同。

历史训练与校准脚本按原版本保留；版本号不表示医疗成熟度。软件版本和模型版本分别管理。

## 公开演示能证明什么

合成演示可验证特征变换、回归训练、校准/测试分离、模型保存与加载、API 和静态资源能协同运行。其随机输入和人为标签只属于软件测试夹具。它不能证明现实数据上的准确率、公平性、校准质量或临床价值。

单元测试和本次演示均不读取原项目的数据或模型，也不向在线服务发送身体参数。完整 NHANES 复现需自行取得来源数据，重新训练和记录环境，不能把演示分数写成真实研究结果。

## 公开整理

纳入 Python 源码、原生前端、研究脚本、合成测试和构建配置。未纳入原始/处理后的数据、训练模型、个人输入、日志、截图、历史结果、私有笔记、环境缓存和原 Git 历史。新增加的演示在运行时生成数据并清理临时模型。

公开版移除了模型信息接口中硬编码的历史指标回填；模型包未提供的指标显示为空，而不是继承别的模型的成绩。合成模型的清单及响应会显式标识其数据性质。
